# 蟑螂大作战

**一只拖鞋，五间房。打穿虫群，回到现实。**

[▶ 在线试玩《蟑螂大作战》](https://cockroach-battle.zackliny.chatgpt.site)

加班到两眼一黑之后，主角在杂物间醒来，发现自己缩小到了蟑螂的尺寸。手边只有一只旧拖鞋，暗处的虫母还在不断产卵。想回到现实，就得一间一间闯过去。

## 怎么玩

- **走位与自动攻击**：手机拖动屏幕摇杆；电脑使用 WASD 或方向键。靠近蟑螂时，武器会自动攻击。
- **从拖鞋开始成长**：击杀获得经验，升级时从三项奖励中选择。后续可以获得喷雾、电蚊拍、电锯、弹弓等武器，并叠加符文。
- **组合自己的打法**：厚底重拍强化拖鞋；寒霜、连锁闪电和霜雷共振可以联动；也能走击退碰撞、燃烧扩散或部位破坏路线。
- **寻找虫母**：虫母藏在房间里并持续召集蟑螂。消灭虫母、清理残敌，才能进入下一间房。
- **闯过五间房**：第一关让你熟悉走位，之后蟑螂的数量、速度、生命值和抗性逐步提升。被击中三次就会失败，本轮成长清零。

蟑螂会探动触须，突击时展翅拍动。足、翅、眼睛可以被破坏，断翅后会失去飞行能力。

## 操作

| 平台 | 移动 | 攻击 |
| --- | --- | --- |
| 手机 | 拖动屏幕摇杆 | 自动 |
| 电脑 | WASD / 方向键 | 自动 |

开场故事可以跳过，也可以在开始界面重看。首次进入需要加载游戏资源。

## 本地运行

```bash
python scripts/restore-github-chunks.py
npm run build
python -m http.server 8000 -d dist
```

然后打开 `http://localhost:8000`。`godot/` 包含 Godot 4.7.2 的游戏脚本和项目入口；大文件分段的校验清单见 `docs/github-chunk-manifest.json`。
